# 📋 Журнал изменений (Changelog)

Все заметные изменения в проекте **Sentinel Community Manager (SCM)** документируются в этом файле.

Проект придерживается семантического версионирования [SemVer](https://semver.org/lang/ru/).

---

## [1.0.1] — 2026-09-22

Глобальное обновление безопасности, сетевой устойчивости и производительности по результатам глубокого инженерного аудита через **Claude Opus 4.8** (полный отчёт: [CLAUDE_4.8_AUDIT_REPORT.md](CLAUDE_4.8_AUDIT_REPORT.md)).

### 🛡️ Безопасность и Windows DPAPI
- **Устранён P0-сбой инициализации DPAPI**: создание `StoreService` и инициализация `safeStorage` перенесены строго внутрь `app.whenReady()`. Ранее при старте приложения `safeStorage.isEncryptionAvailable()` возвращал `false`, что приводило к сбою чтения зашифрованного токена.
- **Атомарная запись данных (`atomicWriteJson`)**: все операции сохранения (`config.json`, `templates.json`, `activity.json`) переведены на безопасный цикл: запись во временный файл (`.tmp`) → принудительный сброс буферов на диск (`fs.fsyncSync`) → атомарное переименование (`fs.renameSync`). Полностью исключён риск повреждения файлов до 0 байт при аварийном завершении.
- **Защита от затирания шифротекста (`tokenLocked`)**: если ключ временно не удалось расшифровать, при последующем сохранении других настроек зашифрованный токен не перезаписывается пустой строкой.
- **Строгий запрет Plaintext**: при сбоях safeStorage токен ни при каких условиях не записывается на диск в открытом виде.
- **Изоляция секретов от рендерера**: метод `getConfigForRenderer()` исключает поля `token` и `encryptedToken` из IPC-ответов. В UI передаётся только безопасный индикатор `hasToken: boolean`.

### ⚡ Сетевое ядро Bots Long Poll 5.199
- **Автоматический старт при вводе токена**: метод `updateCredentials` теперь автоматически вызывает `this.start()`, если токен был введён в настройках после запуска незалогиненного приложения.
- **Защита от потери сообщений**: коммит нового `lpTs = data.ts` теперь выполняется строго **после** успешной обработки пачки апдейтов, а не до неё.
- **Изоляция сбоев в пачке**: вызов `handleUpdate` для каждого события изолирован в локальный блок `try/catch` — ошибка в одном событии больше не прерывает обработку остальных.
- **LRU-дедупликация событий**: внедрён LRU-кэш обработанных идентификаторов (`seenEventIds` на 2000 записей), предотвращающий дублирование сообщений и реакций при повторной доставке пачки после `failed=2`.
- **Горячий рестарт при пробуждении ПК**: интеграция с `powerMonitor.on('resume')` мгновенно сбрасывает висящий сетевой сокет через `AbortController` и форсирует переподключение к серверам VK.
- **Защита от API-шторма**: при кодах `failed=2` и `failed=3` добавлена обязательная пауза 1000 мс перед повторным запросом.
- **Guard на комментарии**: исправлено падение на событиях `wall_reply_new` без текста (содержащих только вложения).
- **LRU-кэш пользователей**: `userCache` ограничен 500 записями для предотвращения утечек памяти при длительной непрерывной работе.

### 🖥️ Electron Runtime & Архитектура
- **Изоляция рендерера**: включён флаг `sandbox: true` в настройках `webPreferences`.
- **Контроль навигации**: добавлены обработчики `will-navigate` и `will-attach-webview`, блокирующие переход окна на сторонние внешние адреса с сохранением привилегий preload. Внешние ссылки открываются строго в системном браузере по умолчанию.
- **Content-Security-Policy (CSP)**: настроены строгие заголовки CSP с сохранением поддержки встроенного плеера VK Video (`video_ext.php`).
- **Корректный Single Instance Lock**: убран вызов `process.exit(0)` при обнаружении второй копии — приложение завершается штатно через `app.quit()`.
- **Поддержка Read-Only носителей**: при запуске с защищённой от записи флешки или каталога автоматически включается fallback на системный `app.getPath('userData')`.

### 🎨 React 19 UI & Оптимизация
- **Защита пользовательского ввода**: поле ввода в чате очищается только после подтверждения успешной отправки сообщением на сервер; при сетевой ошибке вводится понятное предупреждение.
- **Индикация загрузки**: добавлены спиннеры и визуальные индикаторы отправки сообщений и загрузки медиафайлов.
- **Умный автоскролл**: чат плавно скроллится вниз при новых сообщениях только если пользователь уже находится внизу списка (`atBottomRef`), не сбивая чтение истории.
- **Устранение O(N²) в ленте активности**: фильтрация и дедупликация каскадных реакций VK оптимизированы и мемоизированы через `useMemo`.
- **Устранение IPC-шторма**: слайдер громкости уведомлений в настройках переведён на `debounce` (300 мс).
- **Улучшения доступности**: закрытие просмотрщика медиа по нажатию клавиши `Escape`, кроссплатформенная формулировка автозапуска и улучшенная стилизация чекбоксов.

## [1.0.0] — 2026-09-20

Первый публичный релиз десктопного менеджера сообществ ВКонтакте **Sentinel Community Manager (SCM)**.

### Основные возможности:
- Прямой мониторинг через Bots Long Poll 5.199 без браузерного оверхеда.
- Встроенная поддержка реакций на сообщения.
- Динамический Theme Engine с 6 цветовыми схемами и настройкой масштабирования UI.
- Истинная портативность (True Portable) с хранением данных в каталоге `data/`.
- Поддержка системного трея Windows 11 с индикатором непрочитанных сообщений.
- Быстрые текстовые шаблоны ответов.
- Модуль онбординга с проверкой прав доступа к сообществу.
